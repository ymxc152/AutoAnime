## 阅读顺序

1. 新用户先阅读仓库根目录的 [README.md](../README.md)。
2. 二次开发先阅读架构文档，了解 scanner → parser → resolver → planner → executor 主链路。
3. 部署或开发 WebUI、Worker、人工纠正功能时，再阅读 WebUI 与数据层规划及实施清单。

## 当前事实来源

- 标题及季度规则：`autoanime_v3/data/aliases.json`
- 运行配置模板：`config.v3.ini.Template`
- Web Schema 与迁移：`autoanime_v3/db/schema.py`、`autoanime_v3/db/migrations.py`
- Web/API 应用服务边界：`autoanime_v3/services/`、`autoanime_v3/api/app.py`
- WebUI：`webui/src/`
- Windows 服务入口：`AutoAnimeWeb.py`、`AutoAnimeWorker.py`、`deploy/windows/`
- 回归测试：`tests/test_v3_*.py`
