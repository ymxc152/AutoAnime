## 产品约束（不要写成相反的文档）

- 一个扫描方案绑定 **一个下载源 + 一个资料库**；改绑会 `revision + 1`。
- Agent **不得发明目标路径**；唯一目的地来自 `planner.build_plan`。
- 无人值守默认是 qB webhook；向导会把该方案设为 `auto_apply_safe` + `mode=link`。新建方案默认仍是 `review_all`。
- `auto_apply_safe` 只入队 `execute_plan`，不在扫描进程里直接执行文件。
- **必须同时运行 Worker**，否则扫描/执行/回滚会停在队列里。
- 备份可创建/列出；**没有** `POST /backups/{id}/restore` HTTP API。
- Webhook 路径必须落在绑定源根内；Linux 风格路径在 Windows 源上会 409 `path_outside_root`，没有路径翻译器。
