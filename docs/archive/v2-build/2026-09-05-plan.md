## 0. 已定架构决议

- **决议 #1**:单用户本地工具(NAS/Docker 自部署),明确不做多用户 Web 服务
- **决议 #2**:前端保 React 19 + Tailwind 4 + 自建组件库 + @xyflow/react,放弃 Vue3+Naive UI;**UI 代码全新编写,不复用 AnimeAgent/AutoAnime 旧 UI**(2026-09-06 修订)
- **决议 #3**:新主干 + 资产移植,不做渐进改造。旧识别管线零移植(长期不稳定);移植清单 = openai_client 槽位轮换/熔断器、cache 设计思想(重实现)、真实文件名语料+老 pytest(TDD 验收标准)、React 前端
- **决议 #4**:所有状态进 SQLite,废除文件态缓存
- **架构评审补丁(2026-09-05 二次确认,侧会话评审结论;①分支策略已拍板)**:M1 骨架补齐 5 项缺口 —— organize/(naming/mover/upgrade/rollback)、series.media_type(TV/MOVIE/OVA/SPECIAL)、schedule_state 表、daily_metrics 表(事件总线汇聚)、CLI queue/confirm 子命令;另有表级修正:release_record 目标多态(episode_id/season_id 二选一)+torrent_hash 去重、pending_queue 带 status/resolution、audit_log 加 operation_id 批次、parse_memory unique(key_level,key_hash)+fansub;工具链定为 async SQLAlchemy2.0+aiosqlite+pydantic 配置;v2 分支直接删旧 autoanime/ 包(不挪 legacy/),AutoAnimeMv.py 入 legacy/
- **模块化原则**:核心圈不可插拔(领域模型/状态机/管线顺序/评分/记忆表结构),外圈全部接口化(识别器/元数据源/下载网关/通知/仲裁器);依赖只向内指;接口 = Protocol + 注册表,窄接口;插件无状态;旁路功能走事件总线;**优雅降级**(关 L3 → LOW 全进人工队列,不是崩溃);不做动态加载/插件市场(backlog)

## 1. 识别架构要点(专题拷问结论 A-G)

- **扫描层**:识别最小单元 = 视频文件;文件夹名 = 上下文佐证;字段冲突文件名优先且降档;解析结果带 evidence 字段
- **三档置信度**(离散,可解释):HIGH(直接归档)/MEDIUM(进 L2)/LOW(进 L3);整季包/剧场版/双集数/标题内季号为一等合法形态
- **L1 规则**:锚点切分法(S01/1080p/WEB-DL 为分水岭);剧名段整段验证不内切;MWeb 方言(Anime. 前缀、来源站表);方言 A-G 见 notes/samples/命名方言分析.md
- **L2 记忆**:两级 key(剧目级为主力、精确级兜底);占位符抽象({ep}/{season});粗原型实测 2606 文件 → 458 剧目级 key,309 key 覆盖 94.3%;信任分 = 命中/(命中+纠错);bypass 黑名单
- **放送进度**:订阅时预生成全季集表(含 air_date)存库,每周校准;无数据不拦截只降级
- **API 匹配**:类型硬过滤(仅动画)、多信号打分(标题 0.6/年份 0.2/流行度 0.2)、Bangumi+TMDB 交叉互认才双写 id
- **自动仲裁**:Agent = 带固定工具清单的验证器(查详情/核集数/查 alias/查放送日历),≤2 轮,证据链免费为主;多候选不定案与 L3 失败先走证据仲裁,裁不动才进人工
- **自动确认三条件**(全满足免人工免观察期):剧名精确命中+类型过滤通过、集数过真实性闸门、上下文自洽;自动定案进审计,频繁被撤销 → 自动收紧;自主权限三档(保守/平衡/激进),默认平衡
- **L3 契约**:单文件快路径一等公民(订阅场景秒归档,永不凑批);机会主义合批(队列自然堆积 ≥5 个同目录同字幕组才打包,上限 20,逐项校验失败不连坐);小模型先上、校验不过才升级
- **北极星指标**:人工介入率 <2%,面板可视化,突增告警
