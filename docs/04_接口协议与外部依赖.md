# 接口协议与外部依赖

## 功能背景
项目通过多源 API 对识别出的文件名信息进行标准化。当前识别链路已升级为：统一 JSON 解析、字段显式校验、内存+持久化缓存，并支持 OpenAI 直接输出剧名/季/集。

## 功能目标
- 明确所有外部接口用途、协议和调用入口。
- 记录关键配置项与安全注入方式，避免密钥硬编码。

## 功能边界
- 仅覆盖当前脚本实际调用接口。
- 不包含第三方平台的账号申请流程。

## 架构概览
- 文件识别入口：`Processing_Identification() -> Auxiliary_OpenAIIdentifyFileInfo()`
- 名称标准化入口：`Auxiliary_Api()`
- 识别顺序（默认）：
  1. `OpenAIApi`（LongCat OpenAI 兼容）
  2. `BangumiApi`
  3. `BgmApi`
  4. `TMDBApi`
- 当上游返回失败或空结果时继续回退。
- 所有 HTTP 返回统一通过 `response.json()` 解析（非 JSON 返回直接判定失败）。

## 外部接口清单
| 接口名称 | 协议 | 默认地址 | 使用入口 | 用途 | 备注 |
| --- | --- | --- | --- | --- | --- |
| OpenAI 兼容接口 | HTTPS + JSON | `https://api.longcat.chat/openai/v1/chat/completions` | `OpenAIApi()` / `Auxiliary_OpenAIIdentifyFileInfo()` | 提取标准番剧名，或直接识别剧名/季/集 | 默认优先 |
| Bangumi 搜索 | HTTPS + JSON | `https://api.bgm.tv/search/subject/{name}` | `BangumiApi()` | 中文名称优先匹配 | 回退 |
| BGM 搜索 | HTTPS + JSON | `https://api.bgm.tv/search/subject/{name}` | `BgmApi()` | 小结果集补充匹配 | 回退 |
| TMDB TV 搜索 | HTTPS + JSON | `https://api.themoviedb.org/3/search/tv` | `TMDBApi()` | 备用名称匹配 | 回退 |

## 配置说明
| 配置项 | 类型 | 默认值 | 作用 | 安全建议 |
| --- | --- | --- | --- | --- |
| `USEOPENAIAPI` | bool | `True` | 是否启用 AI 识别 | 建议保留开启 |
| `OPENAI_PRIORITY_FIRST` | bool | `True` | 是否 AI 优先 | 推荐 `True` |
| `OPENAI_IDENTIFY_ALL` | bool | `True` | 是否由 AI 直接识别剧名/季/集 | 推荐 `True`，失败自动回退本地识别 |
| `OPENAI_BASE_URL` | str | `https://api.longcat.chat/openai` | OpenAI 兼容网关地址 | 可按供应商替换 |
| `OPENAI_MODEL` | str | `LongCat-Flash-Chat` | 调用模型 | 与网关支持模型一致 |
| `OPENAI_TIMEOUT_SECONDS` | int | `60` | 请求超时秒数 | 网络差可适当增大 |
| `OPENAI_API_KEY` | str | 空 | 本地直填 key（可选） | 公开仓库禁提交 |
| `OPENAI_API_KEY_ENV` | str | `OPENAI_API_KEY` | 环境变量名 | 推荐用环境变量注入 |
| `TMDB_BEARER_TOKEN` | str | 空 | 本地直填 TMDB token（可选） | 公开仓库禁提交 |
| `TMDB_BEARER_TOKEN_ENV` | str | `TMDB_BEARER_TOKEN` | TMDB token 环境变量名 | 推荐用环境变量注入 |
| `CACHE_DIR` | str | `.cache` | 持久化缓存目录 | 建议加入备份策略 |
| `CACHE_TTL_SECONDS` | int | `86400` | API 缓存有效期（秒） | 过短会增加外部 API 压力 |
| `USEBANGUMIAPI/USEBGMAPI/USETMDBAPI` | bool | `True` | 回退 API 开关 | 建议至少保留一个回退 |

## 调用关系
- `Processing_Main -> Auxiliary_Api -> try_apis -> OpenAIApi -> BangumiApi -> BgmApi -> TMDBApi`
- `Processing_Main -> Processing_Identification -> Auxiliary_OpenAIIdentifyFileInfo(成功时直接返回剧名/季/集)`
- 命中任一有效结果即返回，不再继续调用后续接口。
- API 结果缓存链路：`ReadApiCache -> 命中返回 / 未命中请求 -> WriteApiCache -> 程序退出时落盘`

## 风险点
- 网关变更导致兼容路径变化。
- 第三方 API 限流或响应结构变化。
- 错误配置导致无法读取 key/token（已通过日志脱敏提示辅助定位）。
